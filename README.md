# Сервис публикации статей

## Назначение

**Сервис публикации статей** — это веб-приложение на языке **Python**, предназначенное для создания, публикации и обсуждения статей.

Сервис позволяет авторам размещать материалы, распределять их по категориям, а пользователям — читать статьи и оставлять комментарии.

## Целевая аудитория

Сервис предназначен для:

* авторов, которые хотят публиковать собственные статьи;
* читателей, заинтересованных в тематических материалах;
* блогеров и журналистов;
* небольших редакций и информационных проектов;
* образовательных сообществ.

## Предметная область

Предметная область проекта — **публикация и управление текстовым контентом**.

Система хранит информацию об авторах, статьях, категориях и комментариях. Автор может создавать и публиковать статьи. Каждая статья относится к определённой категории и может содержать комментарии пользователей.

## Основные сущности

### Автор

Представляет пользователя, который создаёт статьи.

Основные поля:

* `id` — уникальный идентификатор;
* `name` — имя автора;
* `email` — электронная почта;
* `bio` — краткая информация об авторе.

### Статья

Основные поля:

* `id` — уникальный идентификатор;
* `title` — название статьи;
* `content` — содержимое статьи;
* `author_id` — идентификатор автора;
* `category_id` — идентификатор категории;
* `created_at` — дата создания;
* `updated_at` — дата последнего изменения;
* `status` — статус публикации.

### Категория

Используется для группировки статей по темам.

Основные поля:

* `id` — уникальный идентификатор;
* `name` — название категории;
* `description` — описание категории.

Примеры категорий:

* программирование;
* технологии;
* наука;
* образование;
* новости.

### Комментарий

Основные поля:

* `id` — уникальный идентификатор;
* `article_id` — идентификатор статьи;
* `author_name` — имя автора комментария;
* `text` — текст комментария;
* `created_at` — дата создания.

## Основные функции

Сервис должен предоставлять следующие возможности:

* создание и редактирование статей;
* просмотр списка опубликованных статей;
* просмотр отдельной статьи;
* создание и управление категориями;
* привязка статьи к категории;
* фильтрация статей по категориям;
* поиск статей;
* добавление комментариев к статьям;
* просмотр, удаление комментариев;
